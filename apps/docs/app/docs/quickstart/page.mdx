# Quickstart

Use this page as the shortest path from clone to a useful first run of Supabase Auth Seeder. The goal is not to understand every file yet; the goal is to install dependencies, provide required configuration, and run the command that proves the project is alive.
## What You Will Accomplish
- Prepare the repository with the detected package manager.
- Add the minimum environment configuration needed for runtime behavior.
- Run the primary workflow so you can confirm the project is usable before exploring advanced docs.
## Before You Start
This repository appears to use `bun` as its package manager.
Environment-backed behavior was detected, so configuration is part of the first-run path.
## Recommended First Run
1. Install dependencies with `bun install`.
2. Copy `env.example` to `.env` and set the required values.
3. Run `bun run seed` to exercise the main workflow.
## Useful Commands
These commands are useful after the first run because they describe the repeatable workflows exposed by the repository.
- `seed`: `tsx src/index.ts`
- `seed:batch`: `tsx src/batch-seeder.ts`
- `seed:conservative`: `tsx src/conservative-seeder.ts`
- `seed:small`: `tsx src/index.ts --users=1000`
- `build`: `tsc`
- `dev`: `tsx watch src/index.ts`
## Useful CLI Options
- `--batch=NUMBER`: Override batch size')
- `--concurrent=N`: Override number of concurrent batches')
- `--debug`: Enable debug logging')
- `--help`
- `--users=NUMBER`: Override total number of users to seed')
